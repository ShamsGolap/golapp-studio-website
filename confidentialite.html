CONFIDENTIALITÉ

Une vitrine sans surveillance.

Cette première version du site GolApp Studio a volontairement été conçue sans outil d'analyse d'audience, sans pixel publicitaire et sans cookie déposé par le site lui-même.

Données collectées par GolApp Studio

Le site ne contient actuellement aucun formulaire, aucun espace membre et aucun système de suivi. GolApp Studio ne collecte donc directement aucune donnée personnelle lors de votre consultation de ces pages.

Hébergement

Le site est hébergé avec GitHub Pages. GitHub peut traiter certaines données techniques nécessaires au fonctionnement et à la sécurité de son service, notamment des informations de connexion. Ces traitements relèvent de la politique de confidentialité de GitHub.

Liens externes

Certains liens peuvent vous conduire vers GitHub ou, à l'avenir, vers les pages officielles des applications GolApp Studio. Les sites tiers appliquent leurs propres politiques de confidentialité.

Évolution de cette page

Si le site évolue avec de nouvelles fonctionnalités, cette page sera mise à jour pour expliquer clairement les données éventuellement traitées et leur finalité.
