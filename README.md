# GolApp Studio — Website

Official website for **GolApp Studio**, an independent mobile app studio.

## Live site

GitHub Pages: https://shamsgolap.github.io/golapp-studio-website/

## Stack

The first version is intentionally lightweight:

- Semantic HTML
- Modern CSS
- Vanilla JavaScript
- No framework
- No third-party analytics
- No third-party font or asset dependency

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static HTTP server.

## Structure

- `index.html` — landing page
- `styles.css` — responsive design system and layout
- `script.js` — navigation and progressive reveal interactions
- `confidentialite.html` — website privacy notice
- `favicon.svg` — GolApp Studio mark

## Deployment

The website is deployed through GitHub Pages from this repository.
